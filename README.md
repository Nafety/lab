# Le Labo

Un laboratoire ancien et magique à explorer en 3D, dans le navigateur.

## Lancer en local

Il faut [Node.js](https://nodejs.org) 20 ou plus.

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:5173.

## Construire pour la mise en ligne

```bash
npm run build
```

Le site statique est généré dans `dist/`. `npm run preview` permet de le tester avant de le publier.
